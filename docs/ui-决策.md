# UI 决策记录

> 开发前确认的界面层决策，`AppTheme`、`app.css` 与各 `View` 以此为准。

## 1. 界面语言

- **中文为主 + 英文标题**：按钮、提示、日志、结算文案用中文；游戏标题保留英文 `CSU Poker Game`。

## 2. 音效与音量

- 音量滑条为**纯 UI 滑条**：真实存取设置（`UserPreferences`），但本期**不实例化 `MediaPlayer`、不加载任何音效文件**。后续接入音效时再挂 `volume`。

## 3. 主题

- **仅深色**（与计划书浅色 token 不同）。界面整体深色，牌桌深绿为底。
- 深浅色不提供切换入口，后续如需浅色再按变量扩展。

## 4. 首页副标题

- 副标题文案：**「中南棋牌室」**。

## 5. 窗口尺寸

- 默认最小宽高 `1100 × 720`；窗口宽度不足 `980` 时给根节点加 `ScrollPane`（用户手动拖小时兜底，避免控件不可达）。

## 6. 深色 CSS token（建议值）

| token | 值 | 用途 |
|-------|-----|------|
| `-color-bg` | `#14161a` | 页面背景 |
| `-color-table` | `#0f5132` | 牌桌底色（深绿，沿用计划书） |
| `-color-surface` | `#20242c` | 卡片/面板/手牌表面 |
| `-color-surface-2` | `#2c323c` | 浮起/高亮元素 |
| `-color-text` | `#e8e6df` | 主文字（暖白） |
| `-color-text-dim` | `#9aa0a6` | 次要文字 |
| `-color-accent` | `#e0a82e` | 强调/金色（比原 #d99124 略亮，适配深色） |
| `-color-danger` | `#e5484d` | 危险/质疑失败（深色下更醒目） |

> 圆角 `12px`、间距 `8px / 16px / 24px` 沿用计划书。深色配色为建议值，可在开工前微调。
