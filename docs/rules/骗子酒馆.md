# 骗子酒馆（四人课堂 MVP 规则）

> 本文件为已确认的课堂 MVP 开发基线，不等同 Steam 原作细节。

## 1. 用牌与目标

- 四人各 **1 滴血**。
- 牌组共 **20 张**：K、Q、A 各 6 张 + 2 张 JOKER。
- **JOKER 是万能牌**，可当作任何牌。
- **目标点数整局固定**：开局从 K/Q/A 随机抽一张，本局所有回合不变。
- 每人发 **5 张**手牌（4×5=20，牌组正好发完，无补牌堆）。

## 2. 回合流程

1. **宣告（DECLARE）**：当前出牌者从手牌打出 1–3 张牌，并宣告这些牌均为本轮目标点数（JOKER 视为目标点数）。
2. **回应（RESPOND）**：出牌者的下家（存活玩家）选择其一：
   - 相信：相信者成为新的出牌者。
   - 质疑：翻开本次所出的牌。

## 3. 质疑结算与俄罗斯转盘

- 翻开的牌全部为目标点数（或 JOKER）→ 宣告属实；否则宣告被拆穿。
- **输的一方上俄罗斯转盘**：宣告属实→质疑者上；宣告被拆穿→宣告者上。
- 俄罗斯转盘：左轮 **6 仓**，开局选定 **bulletCount 颗子弹**（1–6），一局内每次上转盘都是这个子弹数。
- **中弹即淘汰**（1 滴血归 0）；空弹则存活。

## 4. 结算后的续局

1. 所有存活玩家补齐至 5 张。
2. 目标点数**保持不变**（整局固定）。
3. 从受惩罚者的下家开始新一轮。

## 5. 出局与胜负

- 中弹的玩家淘汰（生命归 0）。
- 剩下最后一名存活玩家获胜。

## 6. 已确认的决策记录

| 决策点 | 结论 |
|--------|------|
| 人数 | 四人（1 用户 + 3 AI） |
| 生命 | 1 滴血 |
| 牌组 | K/Q/A 各 6 张 + 2 JOKER = 20 张 |
| JOKER | 万能牌，可当任何牌 |
| 目标点数 | 整局固定，开局从 K/Q/A 抽一张 |
| 惩罚方式 | 输的一方上俄罗斯转盘，中弹淘汰 |
| 转盘配置 | 6 仓，开局选子弹数（1–6），一局不变 |
| AI 策略 | AI1 一直质疑、AI2 一直不质疑、AI3 每次 50% 质疑 |
