## 一、分层架构

```
┌─────────────────────────────────────────────┐
│  View 层 (ui.scene.* / ui.component.*)       │
│  JavaFX 代码只在此层;只渲染快照、转命令     │
├─────────────────────────────────────────────┤
│  Controller 层 (core.player.*)               │
│  接收事件、调用 Model、控制流程              │
├─────────────────────────────────────────────┤
│  Model 层 (core.* / paodekuai / liarspoker)  │
│  纯 Java,零 JavaFX import;保存状态与规则    │
├─────────────────────────────────────────────┤
│  Network 层 (network.*)                      │
│  线程只投递命令,不改游戏状态                │
└─────────────────────────────────────────────┘
```

**依赖方向**:View → Controller → Model;Network → Model(仅经命令投递)。反向依赖一律禁止。

**分层判定**:Model 可脱离界面在 `main()` 里跑完一局(PdkEngineTest / LiarEngineTest 即证明)。

## 五、数据流图

### 出牌数据流

```
点击事件
  → selected(Set<Card>)             [View 层暂存选中牌]
  → PlayPdkCards(cards)             [封装为命令]
  → engine.apply(command)           [Controller 投递到 Model]
  → PdkRules.classify(cards)        [识别牌型]
  → PdkRules.canBeat(move, table)   [比较大小]
  → PdkState(新状态)               [不可变推进:移除手牌、换当前玩家]
  → PdkSnapshot(新快照)            [按 viewer 视角生成]
  → PdkTableView.refresh()          [View 重新渲染]
```

### 质疑数据流

```
ChallengeDeclaration(命令)
  → LiarEngine.apply()
  → LiarRules.isTruthful(宣告牌, targetRank)  [判定真伪]
  → LiarRules.whoShoots(truthful, ...)        [定扣扳机者]
  → GunState.wouldHit()                       [掷仓位]
  → alive.remove(shooter) or 继续存活           [淘汰判定]
  → dealHands(random)                         [重新洗牌发牌]
  → LiarState(新状态)                         [保留手枪/淘汰状态]
  → LiarSnapshot(新快照)                      [按 viewer 视角生成]
  → LiarTableView.refresh()                   [View 重新渲染]
```

## 六、AI 使用与核对说明

| AI 辅助项 | 人工核对结论 |
|---|---|
| 类图草稿生成 | 核对:依赖方向单向(View→Controller→Model),无循环依赖;GameEngine 为接口,PdkEngine/LiarEngine 为实现,面向接口成立 |
| 接口签名建议 | 核对:GameEngine 的 4 个方法(snapshotFor/start/apply/legalCommands)语义完整,无多余方法;BotPolicy 为函数式接口,不过度设计 |
| 过度设计检查 | 核对:未引入未使用的设计模式;WireMessage 用 sealed interface 是 Jackson 多态的必要需求,非过度设计 |
| Model 层 JavaFX 检查 | 核对:`grep -r "javafx" core/ paodekuai/ liarspoker/` 返回零结果,Model 层零 JavaFX import |
| 职责粒度检查 | 核对:无 Manager/Context 类;PdkEngine 方法数 4(接口)+ 辅助方法,无超 20 方法的类;LiarEngine 同理 |

## 七、无循环依赖验证

```
ui.scene.* → core.player.* (RuleBotController)
            → paodekuai.* / liarspoker.* (Engine, Snapshot, Command)
            → core.engine.* (接口)
            → core.card.* (Card, Deck)

network.* → core.engine.* (GameCommand, GameSnapshot, PlayerId)
          → paodekuai.* / liarspoker.* (PdkEngine, LiarEngine 构造)
          → core.card.* (不直接,经引擎间接)

core.* / paodekuai.* / liarspoker.* → (无向上依赖,不 import ui.* / network.*)
```

所有依赖方向为 View → Controller → Model,Network → Model,反向依赖为零。
