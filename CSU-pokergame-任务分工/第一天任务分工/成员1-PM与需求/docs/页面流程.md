# 页面流程(2026-09-08,成员 1)

> 成员 4 的开发依据;有出入找成员 1 确认后再改代码。

## 总流转

```
首页(开始游戏 + 右上角设置)
  └─> 模式选择(本地对战 | 局域网联机)
        ├─ 本地对战 ─> 游戏选择(跑得快 | 骗子酒馆) ─> 游戏桌
        └─ 局域网联机 ─> 大厅(创建房间 | 输IP加入) ─> 等待房间 ─> 游戏桌
```

## 设置浮层

- 任何页面右上角都能打开;**叠加在当前页之上,不破坏底层页面**(关闭后原页面状态不丢)。
- 内容:音量滑块、亮度滑块(占位)、查看规则、返回主页、退出。
- 点空白处关闭。

## 规则页

- 从设置进入,两个 Tab 分别展示两个游戏的规则。
- 内容读 `src/main/resources/rules/跑得快.md` 与 `src/main/resources/rules/骗子酒馆.md`。

## 游戏桌布局约定

- 自己的手牌**固定在底部**;其他玩家显示在上方(AI 座位固定横排,不漂移)。
- 游戏状态 / 事件日志在中间区域。
- **非自己回合时,操作按钮禁用**。
- 选中的牌要有明显反馈(白边 + 上移 + 发光,见 `docs/ui-决策.md`)。
