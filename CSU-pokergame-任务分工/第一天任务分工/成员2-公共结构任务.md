## 关键接口契约(照这个写,不要自由发挥)

```java
public interface GameEngine {
    /** 以 viewer 视角返回不可变快照;只含 viewer 自己的手牌。 */
    GameSnapshot snapshotFor(PlayerId viewer);

    /** 开始游戏(洗牌、发牌、定首出)。 */
    void start();

    /** 校验并应用指令;非法指令抛 IllegalArgumentException 且不改变状态。 */
    void apply(GameCommand command);

    /** 返回指定玩家当前所有合法指令。 */
    List<GameCommand> legalCommands(PlayerId player);
}
```

```java
public final class Deck {
    /** 标准 52 张。 */
    public static Deck standard52(Random random);
    /** 跑得快牌堆:48 张,组成以 src/main/resources/rules/跑得快.md 为准。 */
    public static Deck paoDeKuai(Random random);

    public void shuffle();               // 用构造时传入的 Random,保证同 seed 同顺序
    public List<Card> deal(int n);       // 从顶部摸 n 张;剩余不足时抛 IllegalArgumentException
    public int remaining();
}
```
