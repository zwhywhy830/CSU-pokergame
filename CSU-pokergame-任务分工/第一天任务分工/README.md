## 集成约定

- 包结构:`com.csu.pokergame.{core.card, core.engine, core.player, paodekuai, liarspoker, ui, ui.scene, ui.component, network}`
- 分层红线(见 `docs/architecture.md`):
  - 领域层(core / paodekuai / liarspoker)**禁止 import JavaFX**
  - ui 层只渲染快照、把点击转成命令,**不写规则**
  - network 线程只投递命令,不改游戏状态
- 分支:每人一个分支 `day1-成员N`,晚上由 PM 合并到 main
- 提交信息:`feat:` / `test:` / `docs:` + 中文简述,例如 `feat: 增加公共牌类与引擎接口`
