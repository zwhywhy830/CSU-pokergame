## `docs/局域网协议设计.md` 必须包含的目录

1. **总体**:主机是唯一规则裁决方;客户端只发命令、只收自己视角的快照(**绝不下发他人手牌**)
2. **端口与帧**:固定端口 `46888`;TCP 长度前缀帧 = 4 字节 big-endian 长度 + JSON 字节;长度合法区间 `[1, 1_048_576]`,越界立即断开
3. **消息类型表**(明天实现成 Jackson 多态 sealed interface):

| type | 方向 | 载荷 | 说明 |
|---|---|---|---|
| JOIN | 客户端→主机 | 无 | 请求加入,必须是连接后第一条消息 |
| ROOM_SNAPSHOT | 主机→客户端 | RoomSnapshot | 房间变化时广播 |
| START_GAME | 主机→客户端 | GameType + 座位 | 开局,告知该客户端被分配的座位 |
| GAME_SNAPSHOT | 主机→客户端 | GameSnapshot | 每次状态变化,按座位各发各的 |
| SUBMIT_COMMAND | 客户端→主机 | GameCommand | 玩家操作 |
| ERROR | 主机→客户端 | 错误码 | ROOM_FULL / EXPECTED_JOIN / INVALID_COMMAND … |
| GAME_ENDED | 主机→客户端 | 原因 | GAME_OVER / PLAYER_DISCONNECTED / HOST_SHUTDOWN |

4. **座位与命名**:主机 = SEAT_1 =「玩家 1(主机)」;加入者按顺序 = 玩家 2 / 3 / 4;跑得快满 3 人、骗子酒馆满 4 人,第 4/5 个连接者收 `ROOM_FULL`
5. **时序规则**:人数未齐主机不能开局;开局前断开 → 释放座位、广播 ROOM_SNAPSHOT;开局后任一远端断开 → 广播 `GAME_ENDED(PLAYER_DISCONNECTED)`
6. **线程规则**:网络线程只投递命令,引擎只在 JavaFX 线程 `apply`(引用 `docs/architecture.md`)
