# 跑得快（湖南 16 张三人规则）

## 1. 用牌

- 标准 54 张牌移除大小王、红桃/梅花/方块 2、黑桃 A，得 48 张，三人各 16 张。
- 点数：3 < 4 < … < A < 2，只比点数不比花色。

## 2. 牌型

单张、对子、三条、三带一、三带二、顺子（≥5 张，3–A）、连对（≥2 对）、三顺、
飞机带翅膀、四带一、四带三、炸弹（纯四张同点）。

## 3. 比较

- 同型同张数才可比较，按主点数比大小。
- 炸弹可压任意非炸弹牌型。

## 4. 出牌硬规则

- 有大必出：存在可压牌时不能不出。
- 桌面为空（新一轮）必须出牌。
- 连续两家不出后清桌，由最后出牌者继续。

## 5. 报单与胜负

- 剩最后 1 张自动报单。
- 最先出完获胜；结算两名失败者剩牌数。
- 关门（一张未出）按 2 倍计分。
